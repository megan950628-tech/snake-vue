# Evolved Snake
請回答：
## 我的進化版 Snake 改變了原版的哪一個玩法？
撞牆不會死並且撞到自己的身體會分裂
## 玩家需要做什麼新的判斷或操作？
不再需要害怕撞到牆，但增加了炸彈作為死亡方式，另外碰到分裂後的殘骸也會死亡
## 如果有使用 MediaPipe，它如何影響玩法？
沒有使用

首先我個人不太擅長操作，一直死很影響遊戲體驗，所以我希望大家體驗這個玩法的時候能更多享受到遊戲的樂趣而不是不斷受挫

## Design Concept
主要重點在於修改撞牆就死的規則，但因為不能沒有結束遊戲的方式，所以引入了斷尾這個新機制以及簡單的炸彈。先解釋炸彈，和水果一樣隨機刷新在場上，隨著關卡退進場上水果和炸彈會從一增加至三個，作為簡易死亡方式。當遊戲進行到後半段，由於身體佔據較多地圖，撞擊概率也會大幅攀升，但玩家不會因此死亡，而是如同壁虎一樣斷尾求生，撞擊斷開後會提供一秒的逃跑時間，接下來十秒內再次碰觸到殘骸才會真正結束遊戲。原版遊戲主要死亡方式是撞擊自身和撞牆，導致前期也可能迅速結束，只留下撞擊身體在前期較為短小的時候不易觸發，同時即便後期撞到也只會導致變短，反而能以更靈活的身體進行遊戲。遊戲會計算分數提升等級，並根據等級來提升速度，也許可以透過特有的斷尾求生機制來保證畫面不會隨著遊玩進度逐漸被占滿。

## How My Version Is Different
1. 斷尾機制：撞到自己不會直接Game Over，而是切斷後半段身體。被切斷的身體會變成灰色殘骸在場上留存10秒，這10秒內碰到殘骸才會致命。
2. 定時刷新炸彈：場上加入了灰色炸彈，且所有水果與炸彈都有10秒的獨立生存壽命，時間一到便會自動瞬移洗牌，打破了傳統靜態的戰局。
3. 完全穿牆：蛇可以自由穿梭畫布邊界（左進右出、上進下出），讓操作更為流暢，主要致死原因轉移為殘骸與炸彈的交互包夾。

## How To Play
* 基礎操作：使用鍵盤的方向鍵（上、下、左、右）控制蛇的移動方向。
* 穿牆走位：碰到牆壁不會死亡，會從對向邊界穿出，可利用此特性快速閃避危機。
* 危機處理：畫面中央會即時顯示戰場狀態。
  * 若撞擊自身，會扣除部分分數並觸發1秒無敵時間，可利用這1秒迅速離開現場。
  * 斷掉的身體會變成灰色球體，在畫面上倒數10秒，觸碰即死。
  * 隨時注意場上的炸彈，不論是否處於無敵時間，只要碰觸一律直接 Game Over。
